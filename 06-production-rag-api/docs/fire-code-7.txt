Section 7 of the Brightmoor Fire Code covers exits. Every exit in a public building must stay unlocked and free of obstruction whenever the building is open to the public. Exit doors must open outward and must not need a key, a code or special knowledge to open from the inside. Exit signs must be lit and visible from every point in the room. Inspectors may order a building closed at once when an exit is blocked. The fine for a first blocked exit is 500 units, and the fine for a repeat offence is 2000 units.
